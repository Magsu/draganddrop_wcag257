Table operation information Column one has buttons that can be used to reorder the items in the table. With mouse and keyboard you can select an item by pressing Space or Enter, or by clicking the item. After selection the item can be moved up or down using arrow keys, or the buttons that appear before and after the selected row. With mouse you can drag and drop the items without selection.
